# Cabinet Juris

Site vitrine du Cabinet Juris, cabinet juridique situé à Bonamoussadi, Douala, au Cameroun.

## Contenu du site

- Présentation du cabinet et de son approche.
- Domaines d'intervention :
  - droit des affaires ;
  - droit civil ;
  - droit du travail ;
  - droit immobilier ;
  - contentieux et défense ;
  - conseil juridique.
- Présentation de l'équipe.
- Avis clients avec carrousel automatique.
- Articles pratiques.
- Formulaire de contact avec envoi vers WhatsApp.
- Lien de localisation vers Bonamoussadi, Immeuble SGB.

## Structure principale

```text
index.html                         Page d'accueil
style.css                          Styles de la page d'accueil
detail.css                         Styles des pages secondaires
app.js                             Interactions, traductions et carrousels
expertise-*.html                   Pages des domaines d'intervention
article-*.html                     Articles pratiques
assets/                            Images du site
robots.txt                         Instructions pour les robots d'indexation
```

## Lancer le site

Le site est statique. Ouvrez `index.html` dans un navigateur ou servez le dossier avec un serveur local.

Exemple avec Python :

```bash
python -m http.server 8000
```

Puis ouvrez <http://localhost:8000>.
